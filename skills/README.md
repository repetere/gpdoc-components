# GPDoc skills

## GPDoc Markdown

[gpdoc-markdown](gpdoc-markdown/SKILL.md) creates and edits GPDoc Markdown, comments, pending suggestions, JSON slides, notebooks, and scripts with ordinary file tools. No GPDoc account or client is required.
